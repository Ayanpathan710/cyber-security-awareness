# Cyber Security Awareness Program — Website

A single-page, self-contained website (no build step, no dependencies).

## Run locally
Just double-click `index.html` to open it in your browser.

Or, to serve it properly (recommended, avoids any local-file browser quirks):
```bash
cd cyber-security-awareness
python3 -m http.server 8000
```
Then open http://localhost:8000
